# Artifact Integrity

This generated module contains 1992 independent local-only file repair lifecycles, 255 missing-directory lifecycles, and 255 directory-mode lifecycles for the authoritative commercial packaging boundary. Enforcement is disabled in the developer security profile so intentional source edits are never reverted. Release deployments compare each managed artifact to a content-addressed baseline and assign mutually exclusive cause owners to directory absence and mode drift. File restoration is atomic with backup; directory restoration uses an exact identity/mode journal and removes created paths on rollback only while unchanged and empty. 150 historical file IDs, 1 historical directory IDs, and 0 historical directory-mode IDs are retained as non-executable tombstones.
